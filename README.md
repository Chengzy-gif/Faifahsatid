# ห้องทดลองไฟฟ้าสถิต · ฟิสิกส์ ม.5

สื่อการสอนเรื่องไฟฟ้าสถิตแบบโต้ตอบ ทำงานด้วยไฟล์ HTML ไฟล์เดียว ไม่ต้องติดตั้งหรือ build อะไรทั้งสิ้น

**เนื้อหา 8 หน่วย** ประจุไฟฟ้า · กฎของคูลอมบ์ · สนามไฟฟ้า · ศักย์ไฟฟ้า · ตัวเก็บประจุ · เกม · สรุปสูตร · โจทย์ฝึกทำ
**ซิมูเลชัน 7 ชุด** ค่าที่แสดงคำนวณจากสูตรจริง ใช้ตรวจคำตอบโจทย์ได้
**เกม 3 แบบ** ประจุกอล์ฟ 6 ด่าน · ควิซ 26 ข้อ · จับคู่สูตรจับเวลา
**ใบงาน** สุ่มโจทย์ 10 ข้อพร้อมเฉลย สั่งพิมพ์ได้ทันที

---

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด (HTML + CSS + JS อยู่ในไฟล์เดียว) |
| `og.png` | ภาพพรีวิวตอนแชร์ลิงก์ |
| `photos/` | รูปผู้จัดทำ 6 คน (ใช้ในแท็บ 00) |
| `favicon.svg` | ไอคอนบนแท็บเบราว์เซอร์ |
| `vercel.json` | ตั้งค่า header และแคชของ Vercel |

---

## วิธีที่ 1 — อัปขึ้น GitHub ผ่านหน้าเว็บ (ง่ายที่สุด)

1. เข้า [github.com/new](https://github.com/new) ตั้งชื่อ repo เช่น `electrostatics-lab` เลือก **Public** แล้วกด **Create repository**
2. ในหน้า repo กด **Add file → Upload files**
3. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้เข้าไป (`index.html`, `og.png`, `favicon.svg`, `vercel.json`, `README.md`)
4. กด **Commit changes**

## วิธีที่ 2 — ใช้คำสั่ง git

```bash
cd โฟลเดอร์ที่เก็บไฟล์นี้
git init
git add .
git commit -m "สื่อการสอนไฟฟ้าสถิต ม.5"
git branch -M main
git remote add origin https://github.com/USERNAME/electrostatics-lab.git
git push -u origin main
```

เปลี่ยน `USERNAME` และชื่อ repo ให้ตรงกับของตัวเอง

---

## Deploy ขึ้น Vercel

1. เข้า [vercel.com](https://vercel.com) แล้ว **Sign up with GitHub**
2. กด **Add New… → Project** แล้วเลือก repo ที่เพิ่งสร้าง กด **Import**
3. ตั้งค่าตามนี้ (ปกติ Vercel เดาถูกอยู่แล้ว)
   - **Framework Preset:** `Other`
   - **Build Command:** เว้นว่าง
   - **Output Directory:** เว้นว่าง
   - **Install Command:** เว้นว่าง
4. กด **Deploy** รอประมาณ 20 วินาที จะได้ลิงก์ `https://ชื่อโปรเจกต์.vercel.app`

หลังจากนี้ทุกครั้งที่ push โค้ดใหม่ขึ้น GitHub ตัว Vercel จะ deploy ให้อัตโนมัติ

### ทางลัดแบบไม่ใช้ GitHub

ลากโฟลเดอร์นี้ไปวางที่ [vercel.com/new](https://vercel.com/new) ในช่อง deploy แบบลากวาง หรือใช้คำสั่ง

```bash
npx vercel --prod
```

## สิ่งที่ควรทำหลัง deploy

เปิด `index.html` แล้วแก้ 2 บรรทัดนี้ให้เป็น URL จริง เพื่อให้ภาพพรีวิวขึ้นตอนแชร์ลิงก์ใน LINE / Facebook

```html
<meta property="og:image" content="https://ชื่อโปรเจกต์.vercel.app/og.png">
<meta property="og:url" content="https://ชื่อโปรเจกต์.vercel.app/">
```

## หมายเหตุ

- เว็บโหลดฟอนต์และไลบรารี 3 ตัวจาก CDN ได้แก่ **KaTeX** (สูตรคณิตศาสตร์) **Lucide** (ไอคอน) และ **canvas-confetti** (เอฟเฟกต์ในเกม)
- ถ้าเปิดโดยไม่มีอินเทอร์เน็ต สูตรจะแสดงเป็นข้อความธรรมดาและไอคอนจะหายไป แต่ซิมูเลชันและเกมยังทำงานครบทุกอย่าง
- ใช้ได้ทั้งคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์ มีปุ่ม **โหมดฉาย** สำหรับต่อโปรเจกเตอร์ในห้องเรียน
